Aplicación de Tareas

Plataforma para registro y seguimiento de tareas

Sobre el proyecto

Este es un proyecto académico desarrollado durante mi proceso de formación en Tecnología en Análisis y Desarrollo de Software del SENA.

La aplicación permite registrar, organizar y realizar seguimiento a tareas y pendientes mediante una interfaz web.

Objetivo

Poner en práctica conceptos de programación, desarrollo backend y comunicación entre las diferentes partes de una aplicación mediante la construcción de un sistema sencillo de gestión de tareas.

Funcionalidades principales

  • Registro de tareas.
  • Consulta de tareas.
  • Actualización del estado de las tareas.
  • Organización de pendientes.
  • Eliminación de tareas.
  • Visualización de las tareas registradas.
  • Interacción entre la interfaz y el backend.

Tecnologías utilizadas

C#ASP.NET CoreHTMLCSSJavaScript

Desarrollo

Durante el desarrollo se trabajó con una estructura cliente-servidor, buscando comprender cómo la interfaz puede comunicarse con el backend para enviar y recibir información.

ASP.NET Core fue utilizado como parte del desarrollo del backend y C# como lenguaje principal de programación.

Aprendizajes

  • Fundamentos de programación con C#.
  • Desarrollo backend con ASP.NET Core.
  • Comunicación entre frontend y backend.
  • Manejo de datos dentro de una aplicación.
  • Desarrollo de interfaces web.
  • Organización de funcionalidades.

Estado del proyecto

Proyecto desarrollado como parte de mi proceso de aprendizaje en desarrollo de software.
