Google Drive API

Portal web para consulta y visualización de archivos

Sobre el proyecto

Este es un proyecto académico desarrollado durante mi proceso de formación en Tecnología en Análisis y Desarrollo de Software del SENA.

El proyecto consiste en un portal web que permite consultar y visualizar archivos almacenados en Google Drive desde una interfaz propia.

Objetivo

Explorar la integración de una aplicación web con un servicio externo mediante una API, poniendo en práctica conceptos de autenticación, consulta de información y manejo de archivos.

Funcionalidades principales

  • Conexión con Google Drive mediante su API.
  • Consulta de archivos almacenados en Drive.
  • Visualización de información de los archivos.
  • Acceso a los archivos desde una interfaz web.
  • Organización de los elementos mostrados al usuario.
  • Manejo de autenticación para acceder al servicio.

Tecnologías utilizadas

HTMLCSSJavaScriptGoogle Drive APIOAuth 2.0MySQL

Aprendizajes

  • Consumo e integración de APIs.
  • Autenticación mediante OAuth 2.0.
  • Comunicación entre una aplicación y un servicio externo.
  • Manipulación y visualización de información.
  • Desarrollo de interfaces web.
  • Investigación y aprendizaje a partir de documentación técnica.

Estado del proyecto

Proyecto desarrollado como parte de mi proceso de aprendizaje.
